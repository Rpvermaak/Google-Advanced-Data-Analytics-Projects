# Project: Employee Attrition Analysis at Salifort Motors

This repository contains the code and analysis for a capstone project focused on understanding and predicting employee attrition at Salifort Motors, a fictional company. The goal of this project was to provide the Human Resources department with data-driven insights and a predictive tool to improve employee retention.

Project Summary
Employee turnover is a significant challenge for any organization. This project utilized machine learning models to analyze employee data and identify the key factors contributing to attrition. The findings and a predictive model were developed to help Salifort Motors proactively address employee retention issues.

Key Insights
* **High Predictive Accuracy:** Our machine learning models demonstrated high effectiveness, achieving a 96.5% accuracy in predicting which employees are at risk of leaving.

* **Evaluation is a Key Factor:** The "Last Evaluation" score was identified as the most significant predictor of attrition. This suggests that both underperformers and top-performing employees are at risk of leaving, indicating a need for a balanced approach to performance management.

* **Workload Imbalance:** The analysis revealed that employees with either an insufficient or excessive number of projects and working hours are more likely to quit.

* **Tenure-Based Risk:** Attrition risk is highest for employees with 4-5 years of tenure. This highlights the importance of creating clear and motivating career paths to retain employees at this critical stage.

* **Low Satisfaction is a Root Cause:** The analysis consistently showed that low employee satisfaction is a foundational driver of attrition, underlining the need to address the other factors identified.

Next Steps
Based on the insights from this project, we recommend the following next steps for Salifort Motors:

1. **Implement Recommendations:** Address workload imbalance and low employee satisfaction through targeted initiatives. This includes ensuring equitable project distribution and implementing wellness or engagement programs.

2. **Develop Career Paths:** Create structured promotion and career development plans. This will help retain high-performing and long-tenured employees by providing them with a clear vision for their future within the company.

3. **Deploy Predictive Model:** Integrate the developed predictive model into HR workflows. This will allow the HR department to proactively identify employees at risk of leaving and implement preventative measures, such as personalized check-ins or mentorship opportunities.

This project provides a comprehensive, data-driven framework for Salifort Motors to combat employee attrition and build a more stable, satisfied workforce.
